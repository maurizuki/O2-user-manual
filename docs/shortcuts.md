# Keyboard and mouse shortcuts
{: .no_toc }

1. TOC
{:toc}

---

## Files

| Shortcut | Command |
|:---------|:--------|
| **Ctrl+N** | New file |
| **Ctrl+O** | Open |
| **Ctrl+Shift+O** | Reopen |
| **Ctrl+S** | Save |
| **Ctrl+Shift+S** | Save as |
| **Ctrl+P** | Print |

## Objects list

| Shortcut | Command |
|:---------|:--------|
| **Ctrl+Shift+N** | New object |
| **Enter** or double-click | Object properties |
| **F2** | Rename |
| **Ctrl+A** | Select all |
| **Ctrl+click** | Add or remove an object from the selection |
| **Shift+click** | Select a range of objects |

## Fields tab

| Shortcut | Command |
|:---------|:--------|
| **Enter** or double-click | Copy field value |
| **Ctrl+click** | Open link or send e-mail |

## Relations tab

| Shortcut | Command |
|:---------|:--------|
| **Enter** or double-click | Relation properties |
| **Ctrl+click** | Go to the related object |

## Rules tab

| Shortcut | Command |
|:---------|:--------|
| **Enter** or double-click | Rule properties |
| **Space** | Enable or disable the selected rule |
| **Ctrl+Shift+Up** | Move rule up |
| **Ctrl+Shift+Down** | Move rule down |

## View and search

| Shortcut | Command |
|:---------|:--------|
| **Ctrl+F** | Show or hide the search pane |
| **F5** | Refresh |
